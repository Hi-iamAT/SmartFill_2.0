Connect ESP32 to HydroLevel

Register the device in HydroLevel, place its device code and API key in the ESP32 secrets file, then flash the firmware. The ESP32 sends readings and polls for commands over HTTPS.

Keep the API key private. HydroLevel device keys identify and authorize a device. Do not publish the real secrets.h, key screenshots, or logs containing the key. The repository includes only secrets.h.example.

1. Register the device in HydroLevel

  1. Open HydroLevel and sign in to the account that manages the installation.
  2. Go to its Devices page and create/register an ESP32 device. Give it a recognizable name and select the tank/container if the interface asks.
  3. Copy the generated device code and device API key. Store the key securely; if the site displays it only once, save it before leaving the page.

The current repository contains the device firmware, not HydroLevel's server implementation. The names and exact buttons in the Devices page can change; use the device code and key provided by the live HydroLevel interface.

2. Configure the ESP32

  1. Make a local copy of water_meter/secrets.h.example named water_meter/secrets.h.
  2. Fill in the Wi-Fi network and registered device credentials:
#define WIFI_SSID        "YOUR_WIFI_NAME"
#define WIFI_PASSWORD    "YOUR_WIFI_PASSWORD"
#define SERVER_URL       "https://hydrolevel.vercel.app"
#define DEVICE_CODE      "ESP32_CODE_FROM_HYDROLEVEL"
#define DEVICE_API_KEY   "API_KEY_FROM_HYDROLEVEL"
#define FIRMWARE_VERSION "2.0.0"

Keep the server URL without a trailing slash. Install ArduinoJson 7, Adafruit GFX, and Adafruit SSD1306. Compile and flash water_meter/water_meter.ino for the correct ESP32 board. Open Serial Monitor at 115200 baud.

3. What the firmware sends

RequestAuthenticationPurpose
POST /api/readingsX-API-KeyUpload measured distance, level, sensor validity, firmware version, Wi-Fi RSSI, pump state, control mode, and runtime. Default interval is 30 seconds and can be updated by server configuration.
GET /api/device-command?device_code=…X-API-Key; optionally X-Command-Updated-AtPoll the current AUTO/MANUAL mode and pump command about every 5 seconds.

The reading body includes device_code, distance_cm, water_height_cm, water_level_percent, free_space_cm, sensor_valid, firmware_version, wifi_rssi, pump_status, control_mode, and pump_runtime_seconds. It may also include container_id once known.

{
  "device_code": "ESP32_XXXX",
  "distance_cm": 28.4,
  "water_height_cm": 42.1,
  "water_level_percent": 59.8,
  "free_space_cm": 22.4,
  "sensor_valid": true,
  "firmware_version": "2.0.0",
  "wifi_rssi": -53,
  "pump_status": false,
  "control_mode": "AUTO",
  "pump_runtime_seconds": 0
}

4. Verify readings and command control

  1. On boot, confirm Serial Monitor reports Wi-Fi connected. Check HydroLevel's device view for new readings after the upload interval.
  2. Calibrate with the tank empty: press OK to begin, then press OK again at the save prompt.
  3. With the pump physically disconnected, verify AUTO behavior and relay direction. AUTO starts at/below 10% and stops at 50% using local sensor data.
  4. For website control, choose MANUAL in HydroLevel and request ON or OFF. The web app stores a command; the device polls and applies it subject to its local safety rules.

Offline behavior and safety

  • AUTO control is local and does not require HydroLevel or Wi-Fi.
  • MANUAL ON stops if no successful command poll arrives for 30 seconds.
  • The relay is commanded OFF at boot and on invalid sensor readings, missing calibration, a level at or above 50%, or continuous runtime of 15 minutes.
  • Firmware currently uses tls.setInsecure(), which skips TLS certificate validation. Configure trusted certificate validation before using this on an untrusted network.
